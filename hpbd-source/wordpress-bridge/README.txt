HPBD Mobile Bridge install
1. Zip the hpbd-mobile-bridge folder (folder must be at zip root).
2. Upload it as a separate WordPress plugin and activate it on staging first.
3. Requires HPBD Operations 1.3.1 and WooCommerce active.
4. Use HTTPS and a dedicated WordPress Application Password per staff account.
5. Never replace or edit the original HPBD Operations plugin for this bridge.
